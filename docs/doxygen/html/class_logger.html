Detailed Description

Process-wide logger shared by every simulation component.

Two logging modes:

  • Verbose: a log of the events where something changes, through event(): servers added, drained and taken offline, requests rejected by the firewall, and traffic spikes and lulls, plus periodic status lines. Routine work that happens nearly every clock cycle (requests arriving, being assigned and finishing) is only logged for a sample of requests (every request_log_every th one), so the log is not one line per cycle.
  • Quiet: only the starting configuration and the ending summary, which totals every kind of event. event() prints nothing. always() prints in both modes and is used for the summaries.

Messages go to the terminal (with ANSI color when enabled) and, if a log file is open, to that file without color codes.
