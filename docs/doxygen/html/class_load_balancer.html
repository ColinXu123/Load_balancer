Detailed Description

Owns a request queue and a pool of web servers, and runs its clock.

On every call to step() the balancer:

  1. advances each server one cycle and records completions;
  2. retires draining servers that have finished their last request;
  3. hands queued requests to idle servers (FIFO);
  4. records queue and utilization statistics;
  5. applies the scaling rule, unless it is still in a cooldown period.

Scaling rule (thresholds are configurable, defaults 50 and 80):

  • queue > 80 x active servers: add one server;
  • queue < 50 x active servers: remove one server;
  • after either action, wait scale_interval cycles before checking again.

Removal never discards work. An idle server is removed at once; otherwise the busy server closest to finishing is put into draining mode and leaves the pool only after it completes its request.
