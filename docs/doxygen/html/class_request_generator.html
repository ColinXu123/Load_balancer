Detailed Description

Random source of new requests.

Owns the simulation's random number engine. It chooses:

  • the job type, streaming with probability streaming_ratio;
  • a processing time drawn uniformly from the per-type range (processing_time_min/max or streaming_time_min/max);
  • random source and destination addresses. With probability attack_probability the source is drawn from one of the firewall's blocked ranges, which simulates hostile traffic for the IPBlocker to stop.

It also decides how many requests arrive on each cycle. The average rate is arrival_rate requests per cycle, multiplied by a traffic level that changes over time so the load is not flat:

  • a slow wave (traffic_wave_amplitude, traffic_wave_period) that raises and lowers traffic like busy and quiet hours of a day;
  • random spikes (spike_chance, spike_multiplier) where traffic jumps for a while, like a flash sale or a viral link;
  • random lulls (lull_chance, lull_multiplier) where traffic nearly stops, like an upstream outage or the middle of the night. Spikes and lulls last between event_min_length and event_max_length cycles. The number of arrivals on a cycle is drawn from a Poisson distribution with the resulting mean.
