Detailed Description

A single unit of work flowing through the simulation.

Every request carries a source and destination IPv4 address, the number of clock cycles a web server needs to finish it, and a job type character ('P' for processing, 'S' for streaming). The id and creation cycle are bookkeeping fields used for logging and wait-time statistics.
