Detailed Description

Simulates a single web server.

A server holds at most one request. Each call to tick() advances the server by one clock cycle; when the remaining time reaches zero the request is complete and the server becomes idle, ready to ask its load balancer for more work.

A server can be marked as draining when the load balancer wants to scale down. A draining server finishes its in-flight request but accepts no new work, so no request is ever lost during scale-down.
