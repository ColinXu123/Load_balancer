Detailed Description

Simple key=value configuration store with typed getters.

File format: one key=value pair per line. Blank lines and lines starting with '#' are ignored, and anything after a '#' on a line is a comment. The key blocked_range may appear many times; every occurrence is kept. Every getter takes a default that is used when the key is absent or malformed, so the simulation runs even without a configuration file.
