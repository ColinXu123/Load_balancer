Detailed Description

Routes every incoming request through the firewall to a load balancer.

Two modes are supported:

  • Switch mode (use_switch=1): streaming ('S') requests go to a dedicated streaming balancer and processing ('P') requests to a processing balancer. The starting servers are split between the two by streaming_server_share. Each balancer scales and reports independently.
  • Single mode (use_switch=0): one balancer receives everything.

Every cycle the switch asks the RequestGenerator how many requests arrive, filters each through the IPBlocker, and forwards the survivors. It then steps every balancer by one cycle, so all balancers share one clock.
