Detailed Description

Simulated firewall / denial-of-service filter.

Holds a list of inclusive IPv4 ranges. A request whose source address (IP In) falls in any range is rejected before it reaches a load balancer queue. Ranges can be given either as "a.b.c.d-e.f.g.h" or in CIDR form "a.b.c.d/n".
